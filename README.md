# HeadLab — редактор головы Minecraft

Полностью клиентский сайт: открывайте `index.html` в современном браузере. Сервер и сборка не нужны.

## Возможности

- Импорт PNG-скина 64×64 или классического 64×32.
- Редактирование всех 6 граней головы и слоя украшения/шляпы.
- Карандаш, ластик, заливка, пипетка, палитра, undo/redo.
- Интерактивное объёмное превью с вращением.
- Экспорт PNG 64×64: сохраняются только области головы и украшения, всё остальное прозрачно.
- Автосохранение проекта в localStorage браузера.

## Запуск

Просто распакуйте архив и откройте `index.html`. Для полностью локального шрифта удалите первую строку `@import` в `styles.css`; дизайн автоматически использует Inter/Segoe UI.

## Дополнительно

- Автоматическое вращение 3D-головы с возможностью отключения.
- Фильтры для головы и украшения: моноцвет в выбранном оттенке, чёрно-белый, инверсия и усиленный контраст.
- Для каждого фильтра регулируется сила применения; результат можно отменить через историю.
- По умолчанию фильтр действует только на выбранные слой и сторону (например, «Голова · Лицо»). Переключатель «Все слои и стороны» применяет его ко всей голове и украшению.
- Экспорт отдельной PNG-иконки головы 512×512 в ракурсе 3/4 с прозрачным фоном. Слой украшения учитывает переключатель в живом превью.
- Рендер иконок полностью переделан: теперь используется настоящий ортографический кубический 3D-рендер, похожий на стандартные иконки голов Minecraft. Доступны пресеты ракурса, разрешения 64–1024, собственные размеры до 2048×2048 и варианты фона.
- Классический ракурс скорректирован по референсу MC-head icon. Экспорт использует перспективную проекцию, Z-буфер, корректное перекрытие второго слоя и сглаживание краёв.
- Пресет Vanilla GUI 3/4 теперь повторяет стандартное GUI-преобразование Minecraft: ортографическая камера, поворот 30°/45°, ванильное затемнение граней и внешний слой размером 9×9×9 относительно головы 8×8×8.
